# 🐳 Dockerfile Introduction

## 1. Dockerfile Kya Hai?

Dockerfile ek plain text file hai jisme Docker image banane ke instructions likhe jaate hain.

Dockerfile ko Docker image banane ke blueprint ki tarah samajh sakte hain.

```text
Dockerfile
    ↓
docker build
    ↓
Docker Image
    ↓
docker run
    ↓
Docker Container
